Prompt 27:
How can I implement raw terminal input in C to handle arrow key sequences for cursor movement without requiring the user to press Enter?

Response Summary:
The AI explained setting the terminal to raw mode using tcsetattr with flags that disable canonical input, echo, and signal processing. Arrow keys arrive as a three-byte ESC sequence; the handler performs a non-blocking peek after receiving an ESC byte to distinguish a bare ESC key from an ANSI arrow sequence, then maps the sequence to named constants KEY_UP, KEY_DOWN, KEY_LEFT, and KEY_RIGHT for use in the interactive drawing loops.
